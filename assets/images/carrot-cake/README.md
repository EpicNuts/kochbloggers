# Carrot Cake Image Placeholder

Place the hero image for the carrot cake recipe in this folder.

Required file name:
- `hero.jpg`

Recommended image specs:
- Aspect ratio: 4:3 or 16:9
- Minimum width: 1200px
- Optimized JPEG (roughly 150-400 KB)

Used by:
- `index.html` recipe card image source
- `recipes/carrot-cake.html` hero image source

Current fallback behavior:
- If `hero.jpg` is missing, both pages fall back to `assets/images/custard-tarts.jpg`.
